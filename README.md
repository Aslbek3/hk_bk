# HK_BK — Obsidian Eslatmalar Arxivi

Bu repo Telegram orqali yuklangan Obsidian eslatmalar to'plami. Asosan badiiy
asarlar (romanlar/konseptlar) uchun g'oya, kanon va tahlil qoralamalarini
saqlaydi.

**Qisqacha:** `Asarlar/` papkasida aslida **4 ta mustaqil asar** bor —
*Abadiyat Qafasi*, *Frederin*, *Free God* va *Soya Hukmdori (Cid)*. Shu
to'rttasidan **Cid asari eng markaziy va eng ko'p tahlil qilingan** —
`Soya_Hukmdori_Cid.md`, uning tahlili, va unga bog'liq "5000 kishilik
simulyatsiya" bo'limi (`5000_simulation.md` + `prompt_5000_sim.md`) shu
asarning qismlari. `lego_blocks.md` va `deep_analysis_100_300.md` esa
alohida asar emas — barcha asarlarga tegishli umumiy g'oya/tahlil
to'plamlari.
